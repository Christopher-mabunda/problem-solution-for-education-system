# EduPrediction - Student Risk Prediction System

AI-based early warning system that predicts whether a student is at **Low**, **Medium** or **High**
academic risk (based on the final grade G3) and recommends practical actions.

Built with Python, Pandas, NumPy, Scikit-learn, Matplotlib, Seaborn and Streamlit.

| Risk | Final grade (G3) | Meaning |
|---|---|---|
| Low | 14 or higher | On track |
| Medium | 10 to 13 | Monitor closely |
| High | below 10 | Needs support |

## Features
- **Assessment**: five short questions give a risk level, confidence and recommended actions
- **Dashboard**: score the whole dataset or an uploaded CSV, filter by risk, download results
- **Model Performance**: Decision Tree vs Random Forest, confusion matrices, feature importance
- **Chatbot**: simple recommendation chatbot
- **About**: project overview

## Data
Download the UCI **Student Performance** dataset and save the Portuguese file as
`data/student-por.csv` (semicolon separated):
https://archive.ics.uci.edu/dataset/320/student+performance

The `student-por.csv` included here is **synthetic** (generated by `generate_sample_data.py`) so the
project runs out of the box. Replace it with the real file and retrain before reporting any results.

## Run in VS Code
1. Install [Python 3.10+](https://www.python.org/downloads/) and [VS Code](https://code.visualstudio.com/) with the **Python** extension.
2. **File > Open Folder...** and choose the `EduPrediction` folder.
3. Open a terminal (**Terminal > New Terminal**) and create a virtual environment:
   ```bash
   python -m venv venv
   venv\Scripts\activate            # Windows
   source venv/bin/activate         # Mac / Linux
   pip install -r requirements.txt
   ```
   If VS Code asks, select the `venv` interpreter (**Ctrl+Shift+P > Python: Select Interpreter**).
4. Train the model:
   ```bash
   python train_model.py
   ```
5. Start the app:
   ```bash
   streamlit run app.py
   ```
   It opens at http://localhost:8501.

You can also press **F5** (Run and Debug) and choose *EduPrediction: train model* or
*EduPrediction: run Streamlit app*.

> On Windows the interpreter path in `.vscode/settings.json` may need to be
> `${workspaceFolder}/venv/Scripts/python.exe`.

## Upload to GitHub
1. Create an empty repository on https://github.com/new (no README, no .gitignore).
2. In the VS Code terminal, inside the project folder:
   ```bash
   git init
   git add .
   git commit -m "Initial commit: EduPrediction"
   git branch -M main
   git remote add origin https://github.com/<your-username>/EduPrediction.git
   git push -u origin main
   ```
   Or use the **Source Control** tab in VS Code and click **Publish to GitHub**.
3. Anyone who clones the repo runs steps 3 to 5 above. The trained model file is not stored in Git
   (it is in `.gitignore`), so `python train_model.py` recreates it.

## Notes
- G1 and G2 (earlier grades) are the strongest predictors, so predictions are an early warning and
  not a replacement for professional judgement.
- The quick assessment asks five questions (age, gender, study time, absences, G2); remaining inputs
  use dataset defaults unless the optional section is filled in.
- Dashboard CSV uploads need the columns: age, sex, studytime, absences, failures, Medu, Fedu,
  famsup, schoolsup, internet, G1, G2.
